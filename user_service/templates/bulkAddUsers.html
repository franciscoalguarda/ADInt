Bulk add users

Upload a UTF-8 CSV file with the columns id, name, password and role.

Existing users are skipped when their name, password and roles match. If any of these differ, the entire CSV is rejected and existing users remain unchanged.

Every occurrence of an existing ID is checked for conflicts. For new IDs repeated in the same CSV, only the first occurrence is considered.

CSV format

For multiple roles, separate them with | in the role column.

id,name,password,role
1001,Ana Silva,temporary123,Student
2001,Joao Pereira,temporary456,Professor|Exam invigilator
3001,Maria Costa,temporary789,Exam invigilator
4001,Pedro Santos,temporary012,Administrator
